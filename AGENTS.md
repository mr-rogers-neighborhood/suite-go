# AGENTS.md

Suite Go is the mobile member of the Suite: one Android app that is the hub and quick surface for the
suite, and a host for the full applications behind a narrow contract. Capacitor, React 19, TypeScript
strict, Loro CRDT documents, Tailwind-free hand-rolled CSS until the theme system lands. This file is
the entry point for AI agents and the short version for humans.

Read [docs/reference/contract.md](docs/reference/contract.md) before touching the module contract, and
[docs/how-to/add-a-domain.md](docs/how-to/add-a-domain.md) before adding a surface to the shell.

## The two rules

1. **The container never reads a document.** It carries bytes and a name. `.planner`, `.budget` and
   `.canvas` are shapes their own apps own.
2. **The container never learns a domain.** It routes on what a module _declares_. There is no
   `if (module.id === "planner")` anywhere in `apps/go`, and there should never be one.

Both are load-bearing. A change that needs a domain name to work belongs in that domain's module.

## Stack

- pnpm workspaces, no Turborepo. Node 22+, pnpm 12.13.0, TypeScript strict.
- Shell: Capacitor 8 on Android, React 19, Vite 8, `@vitejs/plugin-react`, `vite-plugin-wasm`.
- Documents: Loro CRDT. Its WASM must be resolved by `vite-plugin-wasm`; without it the bundle keeps
  an import the WebView cannot resolve and the failure appears only on a device.
- Native target: `apps/go/android` is generated by `cap add android` and committed. Re-generating it
  loses the hand-edited share intent in `AndroidManifest.xml`.
- Quality: Biome, Vitest. No Playwright yet; device assertions go through `pnpm android:eval`.

## Commands

```sh
pnpm install
pnpm doctor               # toolchain, and the command that fixes each gap
pnpm check                # biome, typecheck, vitest
pnpm android:install      # build, install, launch on the attached device
pnpm android:watch        # the same, again, on every save
pnpm android:devices      # what adb can see
pnpm android:emulator --start suite-go-atd
pnpm android:eval "…"     # evaluate an expression in the running WebView
pnpm android:ax           # the accessibility tree Chromium hands to Android
pnpm android:ax --assert  # fail on an unnamed interactive node
pnpm pack:keygen          # a signing keypair, printed once, never stored
pnpm pack:build -- --dir <dir> --id <id> --name <name> --version <v> --key <base64>
pnpm planner:build        # prove Planner's renderer still builds as a web bundle
```

`planner:build` writes only into `apps/go/planner-dist` and `apps/go/.vite-planner`, so it never dirties
the Planner checkout. It is not wired into the shell yet: [docs/reference/planner.md](docs/reference/planner.md)
carries the one decision that blocks it.

## Verify

The gate is local and runs on every push via `.husky/pre-push`. There is no CI service: a workflow that cannot start looks like a gate and is a comment.

```sh
pnpm check
```

A device is verified with `pnpm android:eval`, not by reading a screenshot: WebView content is invisible
to `uiautomator`, and screenshot diffing guesses. Ask the app what it holds.

Accessibility is verified with `pnpm android:ax`, which reads Chromium's own tree. Do **not** judge a
WebView by `uiautomator dump`: it drops the accessible name of a text field, and it reports an empty tree
when no accessibility service is bound — both of which read as defects that are not there. See
[docs/reference/accessibility-mobile.md](docs/reference/accessibility-mobile.md).

## Conventions

- **Never edit a sibling repository to make this one work.** The suite's product repos are separate
  checkouts; a change needed there is coordinated, not made from here.
- A module is a package that depends on `@suite/go` and exports one `SuiteGoModule`. Its domain logic
  lives with it.
- Registration happens once per mount. `register` is where a domain opens its document, so caching a
  registration across mounts reuses a disposed one.
- Disposal runs as an effect cleanup, so leaving by any route runs it exactly once. `disposeAll`
  survives a module that throws, because one bad module must not leak the others.
- Files are `camelCase.ts`, components are `PascalCase.tsx`, tests are co-located `*.test.ts`.
  Type-only imports use `import type`.
- Conventional commit messages.
- All verification is local. Name the local command; never claim an external service gates `main`.

## Where the sharp edges are

| Edge                                                                    | Why it bites                                                                                                                             |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `@suite/go` resolves to `dist` by default                               | A stale build lets the app run yesterday's contract while tests pass against source. Vite and tsc both alias to source; keep it that way |
| The SDK is often root-owned                                             | Gradle cannot fetch a component AGP asks for. The build prints the `sudo sdkmanager` line; use it                                        |
| Gradle wants build-tools 35 while the distro ships 37                   | Both must be present                                                                                                                     |
| Capacitor injects `--safe-area-inset-*` before `documentElement` exists | CSS reads `max(env(...), var(--safe-area-inset-*))` from both sources                                                                    |
| JDK newer than Gradle supports                                          | Fails with a message that never names the JDK. `scripts/android.mjs` selects 21 or 17                                                    |
